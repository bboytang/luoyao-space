# Proactive Service

Generates low-intrusion outreach candidates.

Inputs:

- recent events
- unresolved topics
- relationship state
- user habits
- time context
- emotional trend
- interaction frequency

Outputs:

- no action
- soft check-in
- follow-up
- share something
- reminder
- voice-call invitation

All proactive actions pass through user-configured notification and autonomy policies.
